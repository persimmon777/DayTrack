# Веб-версия DayTrack

Та же программа в виде веб-приложения: работает в Safari на iPhone без iloader и без переподписи раз в 7 дней.

Адрес: <https://persimmon777.github.io/DayTrack/>

## Установка на iPhone

1. Открой адрес в Safari.
2. «Поделиться» → «На экран „Домой“» → «Добавить».
3. Открывай значком с экрана «Домой»: так приложение работает без адресной строки, офлайн и умеет присылать уведомления.

## Отличия от версии для iPhone

| Что | Веб-версия |
|---|---|
| Виджет и таймер на экране блокировки | Нет: iOS не разрешает их веб-приложениям |
| Уведомления | Приходят, пока приложение открыто или недавно свёрнуто. Надёжные напоминания — экспорт в Календарь iPhone («Настройки» → «Уведомления») |
| Данные | Хранятся в браузере на этом устройстве. Резервную копию нужно сохранять вручную |
| Резервная копия | Тот же формат JSON, что и в iOS-версии: копии переносятся в обе стороны |

Всё остальное совпадает: план и факт, фиксация плана и журнал правок, ключевые слова категорий, расписание с чётностью недель, шаблоны, напоминания, календарь планов, фокусы, большие дела, таймеры отдыха, фокуса и игр, «хочу сбежать», энергия и вечерний разбор, аналитика с графиками и календарём, отчёт для нейросети, советчик, серии, темы.

## Устройство

- `web/src/core` — логика, перенесённая из `Packages/DayTrackCore` один в один, с теми же тестами.
- `web/src/data` — хранилище (localStorage), действия, аналитика, отчёт, уведомления, резервные копии.
- `web/src/ui` — экраны на Preact.
- Сборка и публикация: `.github/workflows/web.yml` (GitHub Pages).

Локально: `cd web && npm install && npm run dev`, тесты — `npm test`.
